# ☕ Проект: База данных соло-кофейни "Coffee"

Данный репозиторий содержит полноценную реляционную базу данных (SQLite) для автоматизации учета соло-кофейни, а также аналитические SQL-запросы для решения бизнес-задач. Проект выполнен в рамках учебного курса по базам данных.

## 📌 Паспорт проекта

*   **Название:** База данных соло-кофейни «Coffee».
*   **Предметная область:** Деятельность предприятия общественного питания. Охватывает учет персонала, ведение меню, оформление заказов и сбор обратной связи (отзывы).
*   **Цель:** Разработать эффективную БД для структурированного хранения данных, автоматизации учета заказов и упрощения управления ассортиментом.
*   **Источник данных:** Синтетические данные, сгенерированные на основе реального меню (вдохновлено датасетами Kaggle).

**Бизнес-польза (Зачем это нужно):**
1.  **Автоматизация учета:** Исключение ошибок при подсчете чека и мгновенное формирование отчетов.
2.  **Объективная мотивация (KPI):** Связь отзывов клиентов с конкретными сотрудниками для прозрачного расчета премий.
3.  **Меню-инжиниринг:** Автоматический поиск непопулярных позиций и расчет скидок для стимулирования спроса.
4.  **Управление загруженностью:** Анализ выручки по временным слотам для внедрения акций в часы затишья.

## 🗂 Структура базы данных

База данных состоит из **7 взаимосвязанных таблиц**, приведенных к 3-й нормальной форме (3НФ). Связи: `1:N` (один-ко-многим) и `M:N` (многие-ко-многим).

1.  `positions` — справочник должностей и базовых окладов.
2.  `employees` — информация о сотрудниках.
3.  `categories` — категории меню (напитки, еда).
4.  `menu_items` — позиции меню (с учетом объема/веса).
5.  `orders` — заголовки заказов (кто принял, сумма, время).
6.  `order_items` — состав заказов (связь заказов и меню).
7.  `reviews` — отзывы клиентов с рейтингом.

## 📊 Ключевые аналитические задачи (Реализованные в SQL)

В папке `sql/` находятся скрипты для создания БД и аналитики. В папке `docs/` — подробное описание запросов и выводов.

1.  **Расчет премий сотрудников.**
    *   *Суть:* Система связывает оценки из отзывов с конкретными сотрудниками, считает средний балл (`AVG`) и через оператор `CASE` начисляет премию.
2.  **Тир-лист кофе для скидок (Меню-инжиниринг).**
    *   *Суть:* База анализирует объемы продаж, делит позиции на категории (Top Seller, Low Demand) и автоматически высчитывает новую цену со скидкой для непопулярных напитков.
3.  **Анализ выручки по 3-часовым интервалам.**
    *   *Суть:* Группировка заказов по времени через `strftime` для выявления часов пик и периодов затишья, чтобы эффективно запускать акции.

## 🚀 Как запустить проект локально

1.  Склонируйте репозиторий.
2.  Откройте SQLite (или DBeaver / DataGrip).
3.  Выполните скрипт `sql/01_create_and_insert.sql` — он создаст таблицы и наполнит их тестовыми данными (100 заказов, меню, сотрудники).
4.  Выполните скрипт `sql/02_analytics_queries.sql` для получения аналитических выгрузок.
