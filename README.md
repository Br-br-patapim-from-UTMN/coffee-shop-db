# ☕ Проект: База данных соло-кофейни "Coffee"

Данный репозиторий содержит полноценную базу данных (SQLite) для автоматизации учета соло-кофейни, а также аналитические запросы для решения бизнес-задач.

## 📌 О проекте
*   **Задача:** Разработать БД для структурированного хранения данных по кофейне, автоматизировать учет заказов, управление ассортиментом и анализ эффективности сотрудников.
*   **Предметная область:** Деятельность предприятия общественного питания (кофейни). Учет персонала, меню, заказов и отзывов.
*   **Источник данных:** Синтетические данные, сгенерированные на основе реального меню (вдохновлено датасетами с Kaggle).

## 🗂 Структура базы данных
База данных состоит из **7 таблиц**, находящихся в 3-й нормальной форме (3НФ):
1.  `positions` — должности и базовые оклады.
2.  `employees` — сотрудники кофейни.
3.  `categories` — категории меню (Кофе, Чай, Десерты и т.д.).
4.  `menu_items` — позиции меню (с учетом объема/веса).
5.  `orders` — заголовки заказов.
6.  `order_items` — детализация заказов (связь заказов и меню).
7.  `reviews` — отзывы клиентов с рейтингом.

*(Связи: Один-ко-многим 1:N и Многие-ко-многим M:N).*

## 🚀 Как запустить проект
1. Склонируйте репозиторий.
2. Откройте SQLite (или DBeaver / DataGrip).
3. Выполните скрипт `sql/01_create_and_insert.sql` — он создаст таблицы и наполнит их тестовыми данными (100 заказов, 60+ отзывов).
4. Выполните скрипт `sql/02_analytics_queries.sql` для получения аналитических выгрузок.

## 📊 Аналитические вопросы и выводы
В папке `docs/` подробно описаны вопросы и результаты.

1.  **Распределение премий сотрудников на основе оценок.**
    *   *Польза:* Автоматизация расчета KPI. Система связывает отзывы с конкретными сотрудниками и начисляет премию на основе `AVG(rating)` и оператора `CASE`.
2.  **Тир-лист кофе и скидки на непопулярные позиции.**
    *   *Польза:* Меню-инжиниринг. База считает продажи, делит напитки на категории (Top Seller, Critical Low) и автоматически рассчитывает новую цену со скидкой для стимулирования спроса.
3.  **Суммарная выручка по трёхчасовым интервалам за каждый день.**
    *   *Польза:* Анализ загруженности. Позволяет выявить часы пик и внедрять акции в часы затишья для выравнивания выручки.
