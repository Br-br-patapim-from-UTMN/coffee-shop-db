# Паспорт проекта: База данных соло-кофейни "Coffee"

## 1. Общие сведения
*   **Название проекта:** База данных соло-кофейни «Coffee».
*   **Тип проекта:** Учебный проект по проектированию и разработке реляционных баз данных.
*   **Инструменты:** SQL, Excel (для визуализации и отчетов), GitHub (для хранения кода и документации).

## 2. Предметная область
Деятельность предприятия общественного питания, в частности, соло-кофейни. 
Область охватывает следующие бизнес-процессы:
*   Учет персонала (должности, оклады, контактные данные).
*   Ведение меню (категории, напитки, блюда, их объем и вес).
*   Оформление заказов (состав чека, итоговая сумма, способ оплаты).
*   Получение обратной связи (отзывы клиентов с рейтингом и текстовым комментарием).

## 3. Цель и задачи проекта
**Цель:** Разработать эффективную реляционную базу данных для структурированного хранения информации о работе кофейни, автоматизации учета заказов и упрощения управления ассортиментом.

**Задачи:**
1. Выделить основные сущности предметной области и спроектировать структуру таблиц.
2. Привести базу данных к 3-й нормальной форме (3НФ), исключив дублирование данных.
3. Наполнить базу согласованными тестовыми данными (100 заказов, 65 позиций меню, отзывы).
4. Разработать аналитические SQL-запросы для решения конкретных бизнес-задач.

## 4. Предполагаемая польза результата (Бизнес-ценность)
Разработанная база данных решает реальные проблемы бизнеса:
*   **Автоматизация учета:** Исключает ошибки при подсчете суммы чека и позволяет мгновенно формировать отчеты по выручке.
*   **Объективная мотивация (KPI):** Система связывает отзывы клиентов с конкретными сотрудниками, позволяя автоматически рассчитывать премии на основе реального рейтинга.
*   **Меню-инжиниринг:** База данных анализирует спрос, выявляет непопулярные позиции и автоматически рассчитывает размер скидок для стимулирования продаж.
*   **Оптимизация загруженности:** Анализ выручки по временным интервалам позволяет выявлять часы пик и внедрять акции в часы затишья.

## 5. Архитектура базы данных
База данных состоит из **7 взаимосвязанных таблиц** (связи 1:N и M:N):
1.  `positions` — справочник должностей и базовых окладов.
2.  `employees` — информация о сотрудниках кофейни.
3.  `categories` — категории меню (кофе, чай, десерты и т.д.).
4.  `menu_items` — позиции меню с указанием цены, объема (мл) или веса (гр).
5.  `orders` — заголовки заказов (кто принял, когда, итоговая сумма).
6.  `order_items` — состав заказов (связь «многие-ко-многим» между заказами и меню).
7.  `reviews` — отзывы клиентов с привязкой к конкретному заказу.

*Все таблицы приведены к 3-й нормальной форме (3НФ). Целостность данных обеспечена внешними ключами (`FOREIGN KEY`) и проверками (`CHECK`).*

## 6. Ключевые аналитические вопросы (Реализованные в SQL)
В рамках проекта были решены три бизнес-задачи:

1.  **Распределение премий сотрудников на основе оценок.**
    *   *Решение:* Связывание таблиц заказов и отзывов, вычисление среднего балла  и применение бизнес-правил через оператор  для начисления бонусов.
2.  **Составление тир-листа кофе для скидок на непопулярные позиции.**
    *   *Решение:* Агрегация продаж , категоризация позиций (Top Seller, Low Demand) и автоматический математический расчет новой цены со скидкой.
3.  **Анализ суммарной выручки по трёхчасовым интервалам.**
    *   *Решение:* Группировка заказов по датам и временным слотам  для выявления наиболее и наименее прибыльных часов работы кофейни.
